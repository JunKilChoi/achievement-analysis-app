# Streamlit → React 기능 일치 체크리스트

이 문서는 `app.py`를 기능 명세로 삼아 새 React 웹앱의 이식 범위를 고정한다.
자동 추출한 모든 UI 호출과 원문은 `STREAMLIT_PARITY_AUDIT.md`에 있으며, 이
문서는 조건 분기·상태 변화·현재 구현 상태·완료 기준을 사람이 검토해 정리한
실행 명세다.

> 구현 진행 메모: 이 문서의 표 안 `현재` 열은 1차 감사 시점의 기준선이다.
> 이후 업로드 누적·중복 제외·파일 사전 검사, 자동 인식 3행 배치, 문항 편집과
> 성취기준별 요약, 네 성취수준 경계, 8개 비AI 분석 화면, 표 정렬·강조,
> 기본/고급 AI와 PDF·Word 경로까지 구현했다. 최종 판정은 실제 브라우저 수동
> 확인 후 표의 상태를 일괄 갱신한다.

## 판정 기준

- **완료**: 원본 기능과 사용자 변경 요구를 모두 충족하며 실제 파일로 검증됨
- **일부**: 계산 또는 기본 화면은 있으나 설명·상호작용·상태·표현 중 일부가 빠짐
- **미구현**: 원본의 실사용 기능을 아직 제공하지 않음
- 기존 Streamlit보다 좋아지는 UI 배치는 허용하되, 정보·계산·조작 기능은 줄이지 않는다.
- 사용자가 새로 지정한 자동 인식 결과 3행 배치와 자동 계산 규칙은 Streamlit
  원본보다 우선한다.
- 학생 파일과 API Key는 서버에 저장하거나 앱 코드에 포함하지 않는다.

| 추가/중복/실패 안내 | 성공·중복 제외·읽기 실패를 별도 박스로 표시 | 미구현 | 각 파일의 처리 결과와 원인 표시 |
| 문항정보표 초기화 | 문항 파일과 관련 편집·분석 캐시 초기화 | 일부 | 명시적 초기화 버튼과 영향 범위 안내 |
| 정오표 목록 초기화 | 정오표·관련 분석 캐시 초기화 | 일부 | 전체 초기화와 개별 제거 모두 제공 |
| 문항정보표 양식 | 앱 양식 XLSX 생성·다운로드 | 미구현 | 원본과 같은 양식을 브라우저에서 다운로드 |
| 양식 도움말 | 나이스 미사용 학교의 작성·재업로드 방법 | 미구현 | 원본 help와 caption을 안내 박스로 제공 |
| 업로드 안내 카드 | 나이스 메뉴 경로, XLS data, 여러 강의실, 주의사항 | 미구현 | 원본 경로와 주의 문구를 빠짐없이 제공 |
| 미업로드 안내 | 두 종류가 모두 필요하고 정오표는 여러 개 가능 | 일부 | 누락된 파일 종류를 구체적으로 알림 |
| 형식 오류 | 읽기 실패 이유 표시 | 일부 | 실패 파일명과 오류 이유, 해결 방법 표시 |

원본 안내에 반드시 포함할 내용:

- 문항정보표: `나이스 → [교과담임] → [정기시험] → [문항정보표관리] → 학년·과목 선택 → [조회] → [출력] → [XLS data]`
- 정오표: `나이스 → [교과담임] → [정기시험조회/통계] → [교과목별학생정오표] → 강의실별 [조회] → [XLS data]`
- 두 자료 모두 XLS data 버전이어야 하며 PDF, 화면 출력용 파일, 임의 편집
  Excel은 정상 인식되지 않을 수 있다는 주의
